# YouTube Homepage Clone 🎥

A front-end practice project that recreates the YouTube homepage using **HTML5** and **CSS3** — built to sharpen skills in Flexbox, CSS Grid, and responsive layout design.

## ✨ Features

- **Header** — YouTube logo, search bar with search/voice-search buttons, upload/apps/notifications icons with hover tooltips, and profile avatar
- **Sidebar Navigation** — Fixed left nav with Home, Explore, Subscriptions, Originals, YouTube Music, and Library links
- **Video Grid** — Responsive grid of video cards, each with a thumbnail, duration badge, channel avatar, title, channel name, and view stats
- **Responsive Design** — Grid adjusts from 4 columns on large screens down to 2 columns on mobile using media queries
- **Interactive Details** — Hover tooltips on header icons and a hover highlight on navigation items

## 🛠️ Built With

- **HTML5** — semantic page structure
- **CSS3** — Flexbox, CSS Grid, media queries, transitions
- **Google Fonts** — Roboto

## 🚀 Getting Started

No build tools or dependencies required.

1. Clone the repo
   ```bash
   git clone https://github.com/<your-username>/<repo-name>.git
   ```
2. Open `index.html` in your browser, or use a local server (e.g. the VS Code "Live Server" extension) for the best experience.

## 📱 Responsive Breakpoints

| Screen width      | Columns in video grid |
|--------------------|------------------------|
| ≥ 1000px           | 4 |
| 751px – 999px      | 3 |
| ≤ 750px            | 2 |
